Ember & Thyme — a cozy hearth-kitchen rush game. You are the cook at a small wood-fired kitchen: build what the order tickets ask for from the ingredient counter, cook the stove dishes on the hearth, and serve before patience runs out. 120-second days, four dishes, six ingredients, synthesized WebAudio sounds, deterministic seeded tickets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — `?seed=N` fixes the ticket order, `?shot=start|play|end` stages a screenshot scene.
